# Калькулятор

Шаблон проекта «Сайт-калькулятор по Issue»: страница калькулятора с двумя полями ввода, кнопками «+», «−», «×» и полем результата.

## Что здесь лежит

- `index.html` — страница калькулятора. Кнопки пока ничего не делают.
- `calc.js` — функции калькулятора `add`, `subtract`, `multiply`. Пока это заглушки.
- `test.js` — готовый тест функций. Его не меняют.

## Как проверить

- Тест: `node test.js` из корня репозитория. Код выхода 0 — все проверки прошли. В шаблоне тест падает: функции ещё не написаны.
- Страница: открой `index.html` в браузере как файл из папки репозитория. Сервер не нужен.

`test.js` и этот README в задаче не меняются.

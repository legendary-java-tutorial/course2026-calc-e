# План: калькулятор — Issue #1

Источник требований: [Issue #1 — «Калькулятор: сложение, вычитание, умножение»](https://github.com/legendary-java-tutorial/course2026-calc-e/issues/1).

## Шаги

1. **Реализовать арифметические функции в `calc.js`:** `add(a, b)`, `subtract(a, b)`, `multiply(a, b)`, сохранив экспорты для готового теста.
   - **Готово, когда** `node test.js` из корня репозитория завершается с кодом выхода 0.

2. **Подключить кнопки в `index.html`:** «+», «−», «×» читают числа из полей `a` и `b`, вызывают соответствующие функции и выводят результат в поле `result`.
   - **Готово, когда** на странице при значениях 2 и 3 нажатие «+» показывает в `result` 5, «−» показывает −1, а «×» показывает 6.

3. **Проверить изменения субагентом `reviewer`:** передать ему `git diff main` и попросить проверить изменения по критериям приёмки Issue #1.
   - **Готово, когда** проверка `git diff main` подтверждает, что `test.js` и `README.md` не попали в diff, и критерии Issue выполнены: `node test.js` возвращает код 0, а три кнопки для 2 и 3 выводят соответственно 5, −1 и 6.

4. **Закоммитить изменения кода только после отдельной просьбы пользователя.** До такой просьбы коммит не создавать.
   - **Готово, когда** после просьбы создан коммит с изменениями реализации; в diff ветки относительно `main` по-прежнему отсутствуют `test.js` и `README.md`.
